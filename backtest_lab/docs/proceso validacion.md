# KULA BALAM IKIGAI — Cuaderno de Ruta y Metodología Cuantitativa

## Filosofía Operativa
1. Validación antes de complejizar: Cero interfaces, servidores o LLMs hasta validar la ventaja matemática en datos históricos.
2. Determinismo puro: Decisiones calculadas solo con inecuaciones matemáticas en Python.
3. Cero fricción: Backtests rápidos y verificables por terminal.

## Fases del Plan
- Fase 1: Descarga y guardado local de datos históricos (BTC/USDT en CSV).
- Fase 2: Cálculo matemático de indicadores (EMA, ATR, RSI) en Python puro.
- Fase 3: Reglas de entrada y salida de UNA sola estrategia.
- Fase 4: Backtest con comisiones y deslizamiento real.
- Fase 5: Evaluación de resultados (Profit Factor >= 1.30 para avanzar).
